Personal backup utility

BTP Factory Backup

An owner-operated desktop backup workflow for securely maintaining recoverable copies of project files using Rclone, Google Drive, and optionally Restic.

What this website is: an informational homepage for a personal OAuth application. It is not a login portal, does not ask visitors to connect their Google accounts, and does not handle backup files or OAuth credentials.

What the application does

The account owner runs Rclone on a local computer to connect to their own Google Drive, check stored backups, and transfer backup files. The intended destination is a dedicated private backup folder. When Restic is used, backup contents are encrypted locally before upload.

Google Drive permissions

The desktop OAuth client requests the Google Drive scope https://www.googleapis.com/auth/drive, which allows access to Drive files, including listing, reading, creating, updating, and deleting them. This is broader than the designated backup folder. Access is used only for owner-controlled local backup and recovery operations, not a service offered to the public.

Privacy and contact

For details about how Google user data and local credentials are handled, please read the privacy policy. For questions, contact the operator through the project's public GitHub issues; do not post credentials or private data there.
