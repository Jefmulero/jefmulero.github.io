Privacy Policy

Effective October 20, 2026 · BTP Factory Backup

Who operates this application?

BTP Factory Backup is a personal, non-commercial backup configuration operated by its account owner. It is not offered as a public application or a multi-user cloud service. This website explains the desktop integration; it does not itself access Google Drive data.

Google data accessed

The desktop application uses Rclone and Google OAuth to access the owner's Google Drive. The requested scope is https://www.googleapis.com/auth/drive, which can permit listing, reading, creating, updating, organizing, and deleting files throughout the authorized Drive. Although the intended backup destination is a specific private folder, the OAuth permission itself is not folder-restricted. Rclone also receives OAuth access/refresh tokens to authorize these operations.

Why data is accessed

The owner uses the connection for backing up and recovering project files, verifying stored copies, and performing owner-directed file management. The configuration is not used for advertising, profiling, or selling personal information. No Google Drive content is transferred to a separate developer-operated server by this website.

Where data is stored and how it is protected

Google Drive holds backup files until the owner removes them. Rclone configuration and authorization tokens are stored locally on the owner's computer; access to that computer and its configuration should be protected. When Restic is enabled, it encrypts backup contents locally before transfer. Independently uploaded files may not be encrypted by Restic.

Sharing and third parties

The owner does not sell Google user data or intentionally disclose it to third parties. Google provides Drive storage and authentication. GitHub Pages hosts this informational website and may process technical access data under GitHub's own privacy practices. This website has no custom advertising, analytics scripts, or visitor-account registration.

Retention, deletion, and revocation

The owner controls how long backup files remain in Google Drive and can delete them there. Locally held credentials can be removed from the Rclone configuration. The Google account holder can revoke the OAuth app's access at Google Account connections. Revoking access stops future API authorization but does not automatically remove backups already stored in Drive.

Changes and questions

This policy may be updated if the backup workflow changes. The current version will remain available at this URL. For non-sensitive questions, contact the operator through the public GitHub issue tracker. Never post passwords, OAuth tokens, or private file contents publicly.
